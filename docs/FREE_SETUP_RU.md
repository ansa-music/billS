# Бесплатный запуск TS

Как запустить TS для сети клубов **без единого платежа**: без аренды сервера (VPS), без домена и без магазинов приложений. Всё, что нужно, — мини-ПК с Ubuntu в главном клубе (он всё равно нужен для HUB) и интернет в клубе.

Инструкция «для чайника»: команды можно копировать как есть. Если что-то пошло не так — в конце есть раздел «Если не работает».

---

## Как это устроено

```
        ┌──────────────── ГЛАВНЫЙ КЛУБ: мини-ПК Ubuntu ────────────────┐
        │  bills-hub    — HUB этого клуба (порт 4310, только сеть клуба)│
        │  bills-cloud  — облако TS + кабинет владельца (порт 4320)     │
        │  база: /var/lib/bills/hub.db и /var/lib/bills/cloud.db        │
        │  бэкапы обеих баз каждую ночь в 03:30                         │
        └───────────▲───────────────────────────▲──────────────────────┘
                    │ Tailscale (шифрованная      │ Tailscale
                    │ частная сеть, бесплатно)    │
        HUB клуба «Север», «Юг»…            телефон и ноутбук владельца
        шлют события в облако               (кабинет, приложение)
```

- **«Облако» — это не чужой сервер.** Это та же программа облака TS, только запущенная на мини-ПК главного клуба рядом с HUB. Хранит данные в файле SQLite — PostgreSQL не нужен.
- **Данные остаются в Казахстане.** Закон РК «О персональных данных и их защите» требует хранить персональные данные граждан РК на серверах в Казахстане. Мини-ПК стоит в вашем клубе — требование выполнено без аренды казахстанского хостинга.
- **Другие клубы сети** подключают свои HUB к этому облаку через Tailscale — так же, как подключались бы к арендованному серверу.
- **Владелец** открывает кабинет с телефона или ноутбука из любой точки, тоже через Tailscale.

Что важно понимать: если мини-ПК главного клуба выключен или без интернета, кабинет недоступен. Клубы при этом **продолжают работать** — каждый HUB копит события у себя и досылает их, когда облако снова на связи. Ничего не теряется.

---

## Шаг 1. Установить HUB и облако на мини-ПК главного клуба

Подключите мини-ПК к интернету, откройте терминал (или зайдите по SSH) и выполните **одну команду**:

```bash
curl -fsSL https://raw.githubusercontent.com/ansa-music/billS/main/deploy/linux/install.sh | sudo bash -s -- --with-cloud
```

Установка займёт 5–15 минут. В конце появится сводка с адресами. Проверить, что всё работает:

```bash
bills status
```

Должны быть зелёными обе службы: `bills-hub` и `bills-cloud`.

> Уже стоит HUB без облака? Та же команда с `--with-cloud` просто добавит облако — база HUB не трогается.

## Шаг 2. Создать компанию и владельца

```bash
sudo bills cloud init --company "Моя сеть клубов" --email owner@example.kz --name "Имя Фамилия"
```

Команда напечатает строку `OWNER_PASSWORD=…` — это пароль для входа в кабинет. **Запишите его** (потом его можно сменить: `sudo bills cloud reset-password --email owner@example.kz`).

## Шаг 3. Подключить HUB главного клуба к облаку

```bash
sudo bills cloud add-club --name "Клуб «Центр»" --connect
```

`--connect` сразу прописывает адрес облака и ключ в настройки HUB этого же мини-ПК и перезапускает его. Через минуту клуб появится в кабинете.

Проверка на самом мини-ПК: откройте в браузере `http://localhost:4320` — это кабинет владельца. Войдите e-mail и паролем из шага 2.

## Шаг 4. Доступ снаружи — бесплатно

Выберите **один** вариант. Рекомендуемый — Tailscale.

### Вариант А (рекомендуемый). Tailscale — частная сеть только для своих

Tailscale соединяет ваши устройства в одну зашифрованную частную сеть поверх интернета. Кабинет видят **только** ваши устройства (телефон владельца, ноутбук, HUB других клубов). В интернет ничего не открывается, на роутере ничего настраивать не нужно, «белый» IP не нужен.

Бесплатного плана Tailscale (Personal) хватает небольшой сети клубов: на момент написания — до 3 пользователей и до 100 устройств. Условия могут меняться — проверьте на https://tailscale.com/pricing.

1. Заведите аккаунт на https://tailscale.com (вход через Google, Microsoft или GitHub — бесплатно).
2. На мини-ПК главного клуба:
   ```bash
   sudo bills tailscale
   ```
   Скрипт установит Tailscale и покажет ссылку вида `https://login.tailscale.com/a/…`. Откройте её на телефоне или ПК, войдите тем же аккаунтом — мини-ПК добавится в вашу сеть. В конце скрипт напечатает адрес кабинета (например, `http://ts-club-center:4320`) и строку `CLOUD_URL=…` для других клубов.
3. На телефоне владельца: поставьте приложение **Tailscale** (App Store / Google Play — оно бесплатное) и войдите тем же аккаунтом. Теперь адрес кабинета открывается с телефона из любой точки.
4. **HTTPS (по желанию, тоже бесплатно):**
   ```bash
   sudo bills tailscale --https
   ```
   Кабинет станет доступен по адресу вида `https://ts-club-center.<ваша-сеть>.ts.net` с настоящим сертификатом. Перед этим в админке Tailscale (https://login.tailscale.com/admin/dns) включите **MagicDNS** и **HTTPS Certificates** — скрипт подскажет. С HTTPS кабинет на iPhone ставится на экран «Домой» как полноценное приложение.

### Вариант Б. Cloudflare Tunnel — адрес в интернете без открытия портов

Подходит, если кабинет нужно открывать с любого устройства **без** установки Tailscale (например, показать партнёру). Порты на роутере не открываются: мини-ПК сам устанавливает исходящее соединение с Cloudflare.

- **Демонстрация за минуту (бесплатно, без регистрации):**
  ```bash
  sudo bills tunnel quick
  ```
  Скрипт напечатает адрес вида `https://случайные-слова.trycloudflare.com`. **Адрес меняется при каждом перезапуске** и Cloudflare не даёт по нему гарантий — только для показа, не для работы.
- **Постоянный адрес (бесплатно, если у вас уже есть свой домен):** домен добавляется в бесплатный аккаунт Cloudflare, в панели **Zero Trust → Networks → Tunnels** создаётся туннель, для него задаётся адрес (например, `cabinet.мой-домен.kz`) → `http://localhost:4320`. Панель покажет токен — передайте его скрипту:
  ```bash
  sudo bills tunnel token <ТОКЕН>
  ```
- Выключить: `sudo bills tunnel stop`.

Что учесть: при туннеле кабинет открыт в интернет (вход по паролю владельца — придумайте надёжный). Данные по-прежнему **хранятся** на мини-ПК в Казахстане; через Cloudflare идёт только трафик (по HTTPS, но шифрование заканчивается на серверах Cloudflare). Если для вас это важно — используйте Tailscale.

### Запасной вариант. DuckDNS — бесплатное имя и HTTPS

DuckDNS даёт бесплатное имя вида `мойклуб.duckdns.org`, которое всегда указывает на текущий IP клуба. Вместе с Caddy получается кабинет по HTTPS с сертификатом Let's Encrypt.

**Работает только если** у клуба «белый» (публичный) IP-адрес и вы можете пробросить порты 80 и 443 на роутере на мини-ПК. У многих провайдеров адрес «серый» (CGNAT) — тогда этот вариант не заработает, берите Tailscale. Скрипт сам сравнит внешний IP с тем, что видит роутер, и подскажет.

1. Войдите на https://www.duckdns.org (через Google/GitHub), создайте поддомен, скопируйте токен.
2. На мини-ПК:
   ```bash
   sudo bills duckdns --domain мойклуб --token <ТОКЕН> --https
   ```
3. На роутере пробросьте порты **80 и 443** на IP мини-ПК. **Порт HUB 4310 не пробрасывайте никогда** — HUB должен быть доступен только из сети клуба.

## Шаг 5. Подключить другие клубы сети

На мини-ПК **главного** клуба создайте клуб и ключ для нового HUB:

```bash
sudo bills cloud add-club --name "Клуб «Север»"
```

Команда напечатает `HUB_ID=…` и `CLOUD_API_KEY=…` — передайте их тому, кто ставит HUB во втором клубе (лучше лично или в мессенджере с исчезающими сообщениями: ключ — как пароль).

В **другом** клубе, на его мини-ПК:

```bash
# 1. HUB клуба (если ещё не стоит)
curl -fsSL https://raw.githubusercontent.com/ansa-music/billS/main/deploy/linux/install.sh | sudo bash
# 2. В ту же частную сеть Tailscale (войти тем же аккаунтом)
sudo bills tailscale
# 3. Подключить к облаку главного клуба
sudo bills connect-cloud --url http://ts-club-center:4320 --hub-id <HUB_ID> --key <CLOUD_API_KEY>
```

HUB на Windows: поставьте Tailscale для Windows (https://tailscale.com/download/windows), войдите тем же аккаунтом и выполните в PowerShell от администратора:

```powershell
powershell -ExecutionPolicy Bypass -File deploy\windows\connect-cloud.ps1 -Url http://ts-club-center:4320 -HubId <HUB_ID> -Key <CLOUD_API_KEY>
```

Список клубов и HUB: `sudo bills cloud list`. Потерян ключ — `sudo bills cloud new-hub-key --hub <HUB_ID>` (старый перестанет работать).

## Шаг 6. Приложения — без магазинов

Страница **«Скачать приложение»** есть в двух местах: в кабинете владельца (ссылка под формой входа и в шапке, адрес `…:4320/#/apps`) и на экранах клуба (меню сотрудника в шапке → «Приложения TS», адрес `#/apps`). Она берёт файлы из **GitHub Releases** репозитория TS (https://github.com/ansa-music/billS/releases) и сама показывает подходящий для устройства вариант.

### Android — установка APK напрямую

1. На телефоне откройте страницу «Скачать приложение» и нажмите **«Скачать APK»**.
2. Откройте скачанный файл. Телефон спросит разрешение на установку из этого источника — **разрешите** для браузера.
3. Нажмите **«Установить»**. Если Google Play Защита предупредит о неизвестном приложении — **«Подробнее» → «Всё равно установить»**: приложение просто не из магазина.
4. Обновление — так же: скачать новый APK и установить поверх, данные сохраняются.

### iPhone и iPad — кабинет на экран «Домой»

Без App Store приложение на iPhone поставить нельзя, но кабинет работает как приложение из Safari:

1. Откройте адрес кабинета в **Safari** (не в Chrome).
2. Нажмите **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **«Добавить»**.
3. На экране появится иконка «TS» — кабинет открывается на весь экран, без адресной строки.

Лучше всего — через адрес с HTTPS (Tailscale `--https` или Cloudflare): тогда вход запоминается надёжнее.

### Компьютер (касса, Windows / Linux) — установщик из GitHub Releases

1. На ПК кассы откройте «Скачать приложение» → раздел «Компьютер» → скачайте установщик (`.msi`/`.exe` для Windows, `.deb` для Ubuntu).
2. Windows может показать синее окно SmartScreen («Система Windows защитила ваш компьютер») — нажмите **«Подробнее» → «Выполнить в любом случае»**. Это потому, что установщик не подписан платным сертификатом.

Планшеты персонала, как и раньше, ставят TS прямо с адреса HUB (PWA, см. README → «Установка на планшет и ПК»).

### Как выложить новую версию (для разработчика)

На GitHub: **Releases → Draft a new release**, тег вида `v0.3.0`, приложите файлы (`*.apk`, `*.msi`, `*.exe`, `*.deb`, `*.AppImage`) и нажмите **Publish**. Страница «Скачать приложение» сразу покажет новую версию. Публичный репозиторий и GitHub Releases бесплатны.

APK подписывайте **одним и тем же** ключом (keystore создаётся бесплатно командой `keytool`) и храните его в надёжном месте: телефон не поставит обновление, подписанное другим ключом.

## Что остаётся платным и когда это понадобится

| Что | Цена | Когда понадобится |
|---|---|---|
| **Google Play** — аккаунт разработчика | **$25 один раз** | когда неудобно ставить APK вручную: много управляющих, автообновления через магазин, доверие «из магазина» |
| **Apple App Store** — Apple Developer Program | **$99 в год** (+ Mac или облачная сборка) | когда владельцу на iPhone нужны надёжные push-уведомления о тревогах; PWA на iPhone их почти не даёт |
| **VPS в Казахстане** | от нескольких тысяч тенге в месяц | **только при росте сети**: много клубов, кабинет должен быть доступен даже при отключении света или интернета в главном клубе, нужен PostgreSQL. Облако переносится на VPS без изменений кода (см. `apps/cloud/README.md`) |
| **Свой домен** | обычно $10–15 в год (`.kz` — у регистраторов РК) | для постоянного красивого адреса через Cloudflare Tunnel; с Tailscale не нужен |
| **Подпись установщика Windows** | ≈ $200–400 в год | чтобы SmartScreen не показывал предупреждение кассиру; для пилота не нужна |
| **Tailscale** платный план | — | только если в сети больше 3 пользователей Tailscale или 100 устройств |

Всё остальное — программа TS, Ubuntu, Node.js, Tailscale (Personal), Cloudflare Tunnel, DuckDNS, Let's Encrypt, GitHub Releases — бесплатно.

## Бэкапы

Каждую ночь в 03:30 таймер `bills-backup.timer` копирует **обе** базы: `hub-*.db.gz` и `cloud-*.db.gz` в `/var/lib/bills/backups/` (хранятся 30 дней). Сделать копию сейчас: `sudo bills backup`.

Копии на том же мини-ПК не спасут от его поломки или кражи, поэтому настройте вторую копию:

- **USB-флешка или второй диск** — в `/etc/bills/hub.env` задайте `BACKUP_SECOND_DIR=/mnt/usb/bills-backups`.
- **Облачный диск** через rclone — `BACKUP_RCLONE_REMOTE=…` (см. `deploy/linux/README.md`). Учтите закон о локализации: копии с персональными данными должны храниться в Казахстане, поэтому зарубежные диски (Google Drive и т. п.) для них не подходят. Надёжный бесплатный вариант — флешка, которую раз в неделю забирает владелец.

Восстановить облако из копии: `sudo bills restore --cloud` (без файла — список копий).

## Если не работает

| Что видно | Что сделать |
|---|---|
| `bills status`: `bills-cloud` не запущен | `bills cloud-logs` — последние строки журнала облака; `sudo systemctl restart bills-cloud` |
| Кабинет не открывается с телефона | на телефоне включён Tailscale? `sudo bills tailscale --status` на мини-ПК — он в сети? |
| Клуб не появляется в кабинете | на мини-ПК клуба `bills health` — смотрите строку про облако; проверьте `CLOUD_URL`, `HUB_ID`, `CLOUD_API_KEY` в `/etc/bills/hub.env` |
| Забыли пароль владельца | `sudo bills cloud reset-password --email owner@example.kz` |
| Адрес trycloudflare перестал открываться | так и задумано — он временный; `sudo bills tunnel quick` выдаст новый |
| DuckDNS: имя есть, но кабинет не открывается | скорее всего «серый» IP у провайдера или не проброшены порты 80/443 — берите Tailscale |
