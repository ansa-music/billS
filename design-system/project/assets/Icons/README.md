# Icons

Иконки разделов кабинета из `CabinetNav.tsx`: сетка 24×24, обводка 2px, скруглённые концы и углы, без заливки.

- `overview.svg` — «Обзор» (столбики выручки).
- `venues.svg` — «Заведения» (витрина).
- `staff.svg` — «Сотрудники» (двое).
- `alerts.svg` — «Уведомления» (колокольчик).
- `download.svg` — «Скачать» (стрелка в лоток).

В коде иконки рисуются inline с `stroke="currentColor"` и берут цвет пункта (`muted`, активный — `accent-text` на `accent`). В этих файлах чернила — `accent` тёмной темы (#2fa56b), чтобы они были видны в плитках; в интерфейсе вставляйте SVG inline и красьте через `color`. Размер — 20px на компьютере, 24px в нижней навигации телефона.
