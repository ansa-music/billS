# Logos

- `ts-monogram.svg` — монограмма TS кабинета: белые буквы на плашке `brand-mark` (#14211b) с внутренней белой обводкой 14%. Тот же рисунок, что `BrandMark` и фавикон. Многоцветная, не перекрашивается.
- `ts-monogram-pos.svg` — монограмма TS кассы: буквы цвета кремы (#f6d3a6, Inter 800) на переходе эспрессо #4a2c18 → #1e120a, обводка #ffe2bf 18%, радиус 9 на 32. Тот же рисунок, что `BrandMark` в `apps/web`. Многоцветная, не перекрашивается.
- `ts-app-icon.svg` — иконка приложения 512×512: плашка с радиальным светом (`brand-mark-lit` → `brand-mark`), радиус 128, геометрические T и S белым. Для манифеста, установки и магазинов.
- `ts-app-icon-512.png` — та же иконка растром 512×512 (PWA, Android).
- `ts-apple-touch-icon.png` — 180×180 для «На экран „Домой“» на iPhone.

Ставьте марку на `bg` или `surface`, не на цветную заливку и не на фото.
