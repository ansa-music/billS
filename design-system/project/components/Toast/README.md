# Toast

Всплывающая тревога в правом нижнем углу — когда облако присылает новую тревогу, пока кабинет открыт. CSS-паттерн `.toasts > .toast` (`apps/cloud-web/src/App.tsx`).

- Текст — ссылка на заведение; клик по ней или «×» закрывает уведомление. На экране не больше трёх, каждое уходит само.
- Подложка — `danger` 14% поверх `surface`, рамка `danger` 55%, точка `danger` 10px, тень `shadow`, радиус `radius-md`.
- Контейнер `.toasts` фиксирован справа снизу (`z-toasts`), ширина до 420px; на телефоне поднимается над нижней навигацией.
- Только для тревог. Подтверждения вроде «Сохранено» показывайте на месте, в самой кнопке («Скопировано»).
