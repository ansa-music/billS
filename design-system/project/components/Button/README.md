# Button

Кнопки кабинета. CSS-паттерн `.btn` из `bundle.css` — на `<button>` или на `<a>` (ссылка-кнопка центрируется как кнопка).

- `.btn` — обычная: `surface-2`, рамка `border`, 600, высота `control` (44px; на сенсорном экране `control-touch`, 48px), бока `space-18px`, радиус `radius-md`.
- `.btn-primary` — главное действие, одно на экран: `accent`, текст `accent-text`; при наведении светлеет (88% + белый).
- `.btn-small` — 36px, 14px: действия в шапке и строках. `.btn-big-text` — 52px, 17px: стартовый экран. `.btn-big` — 64px, подпись `small` под текстом: «Скачать для Windows / компьютер кассы».
- `.link` — серая подчёркнутая ссылка-кнопка для второстепенного; `.link-inline` — `accent` 600 внутри текста («Войти»).
- Недоступная — `disabled`: `opacity-disabled`, курсор not-allowed. Подпись — глагол действия: «Скопировать», «Получить новый код», «Начать бесплатно».
