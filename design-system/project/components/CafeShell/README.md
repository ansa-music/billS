# CafeShell

Оболочка кассы кофейни: боковое меню разделов, верхняя панель с названием экрана, временем, связью и сотрудником. Разметка — `apps/web/src/Shell.tsx`, стили — `shell.css` и правила кофейни под `html[data-business="cafe"]` в `cafe/staff-touch.css`.

- `div.shell[data-section]` → `nav.sidebar` + `div.shell-main` (`header.topbar`, `main.content`) + `nav.bottom-nav` для телефона.
- Боковое меню шириной `nav-w` (232px): марка кассы и название кофейни, пункты `.nav-link` с иконкой 22px — «Касса, Бариста, Экран заказов, Меню, Склад, Счета, Отчёты, Сотрудники, Журнал, Настройки, Выручка»; текущий — `aria-current="page"` заливкой `accent`. Внизу — «● Касса на связи» (`.sidebar-foot[data-online]`).
- Верхняя панель высотой `topbar-h` (64px): марка (на узком экране), название экрана и кофейни, часы клуба, «● На связи», колокольчик тревог, сотрудник (`.actor-pill`: аватар с инициалами, имя, роль), «Сменить», тема, на весь экран.
- Пункты меню видит только та роль, которой они доступны: бариста не видит «Выручку» и «Настройки».
- На телефоне боковое меню заменяет нижняя панель `.bottom-nav` с короткими подписями («Экран», «Персонал»).
