# LoginCard

Карточка входа и стартового экрана — первое, что видит новый владелец на ts-cabinet.pages.dev. CSS-паттерн `.login` (`apps/cloud-web/src/Login.tsx`), вариант `.welcome`.

- Ширина `login-width` (420px, регистрация — 480px), `surface`, радиус `radius`, тень `shadow`, отступ `space-28px` (на телефоне 20px). Страница `.login-page` центрирует карточку по экрану.
- Порядок: марка с названием → заголовок `welcome-title` → три пункта с галочками (`.welcome-points`, глиф «✓» на `accent`) → одна главная кнопка `btn-primary btn-big-text` → «Уже есть аккаунт? Войти» (`.login-alt` + `.link-inline`).
- Под карточкой — серые ссылки `.link`: «Скачать программу для кассы и телефона», «Вход для команды TS».
- Пункты — факты, а не лозунги: «Касса работает даже без интернета», «14 дней бесплатно, карта не нужна».
