# Chip

Чип — выбор одного из нескольких, фильтр или быстрая пометка вместо окна: «без сахара», «погорячее», «в свою кружку». CSS-паттерн `.chips > .chip` из `bundle.css` (касса).

- Чип — кнопка с `aria-pressed`: 40px (48px на сенсорном экране), бока 14px, `radius-pill`, `surface-2`, рамка `border`, 14px/600.
- Выбранный — рамка и внутреннее кольцо `accent`, подложка `accent-soft` (`accent` 16% поверх `surface`), текст `text`. Под курсором — рамка с примесью `accent`.
- Пояснение внутри чипа — `.chip-note` обычного веса цвета `muted`: цена добавки, количество.
- Ряд — `.chips`, перенос и промежуток `space-2`. Чипы заменяют окна с модификаторами: выбор происходит прямо под позицией.
- Для одного значения из фиксированного набора есть готовый компонент `PosSegmented`.
