# TopBar

Верхняя панель кабинета: марка и название компании слева, связь, владелец и «Выйти» справа. CSS-паттерн `.topbar` (разметка в `apps/cloud-web/src/App.tsx`), внутри — живой `TS.BrandMark`.

- Потребитель даёт: название компании (`h1`, `title-lg`), подпись «Кабинет TS», состояние связи и имя владельца.
- `.conn` — точка 8px и слово: `data-online` → `accent` «На связи», без него → `danger` «Нет связи». На телефоне слово скрыто, остаётся точка.
- Справа только маленькие кнопки (`.btn.btn-small`): «Выйти», «Кабинет платформы». Главное действие страницы сюда не ставьте.
- На телефоне (до 700px) панель не переносится: название обрезается многоточием, марка 34px, имя владельца скрыто.
