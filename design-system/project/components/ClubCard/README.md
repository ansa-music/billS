# ClubCard

Карточка заведения на обзоре: название, местное время, связь с кассой, три плитки периода, статус смены и строка «столы · игры · тревоги». CSS-паттерн `.club-card` (`apps/cloud-web/src/Overview.tsx`), внутри — живые `HubBadge`, `StatTile compact` и `Difference`.

- Вся карточка — одна ссылка на страницу заведения. При наведении рамка подкрашивается `accent`, карточка поднимается на 1px.
- `data-problem` (есть открытые тревоги) — рамка `danger` 70%. Не добавляйте других красных акцентов.
- Статус смены (`.shift-status`): открытая — `data-open`, точка `lamp` со свечением и рамка с примесью `lamp`: «Смена №128 открыта с 10:05, Айгерим». Закрытая — серая точка и `Difference` последнего Z-отчёта.
- Подвал (`.club-foot`, 14px, `muted`): `[data-live]` — `lamp` «сейчас идёт 3 игры», `[data-alert]` — `danger` «1 тревога».
- Сетка карточек — `.clubs`: колонки от 420px, промежуток `space-4`.
