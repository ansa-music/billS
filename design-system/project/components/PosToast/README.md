# PosToast

Одна строка внизу по центру — подтверждение, что действие прошло: «Заказ добавлен», «Изменения сохранены». Живой компонент `TS.PosToast` (`Toast` и хук `useToast` в `apps/web/src/ui.tsx`).

- Потребитель даёт `message` (`null` — ничего не показывать) и `onClose`; тап по уведомлению закрывает его, само оно уходит через 5 с.
- Вид — инверсия темы: заливка `text`, текст `bg`, 550, радиус `radius-md`, своя тень; до 560px шириной, 24px от низа, `z-pos-toast`. Появляется снизу за `--dur`.
- Короткое прошедшее время без точки: «Заказ отменён». Ошибки так не показывают — им место рядом с полем или в диалоге.
