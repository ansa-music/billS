# Tag

Короткая метка рядом с заголовком или значением: «новый», «открыта», «ждёт настройки», «расхождений: 2». CSS-паттерн `.tag` из `bundle.css`.

- `tag-new` — `accent` на подложке `accent` 18%: новое (сотрудник, заведение).
- `tag-live` — `lamp` с рамкой: идёт сейчас («открыта», «смена №128»).
- `tag-warn` — `warn`, смешанный с `text`, с рамкой: ждёт («ждёт настройки»).
- `tag-danger` — `danger` на `danger-soft`: проблема («расхождений: 2», «сейчас нет света»).
- 12px, `radius-pill`, 2×8px, без переноса. Одно-три слова строчными; пояснение — в `title`.
