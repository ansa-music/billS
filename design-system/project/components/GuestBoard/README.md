# GuestBoard

Экран заказов для гостей на телевизоре: огромные номера, колонка «Готово — заберите» светится зелёным. Разметка — `apps/web/src/cafe/Board.tsx`, стили — `cafe/staff-touch.css` (`.gb-*`).

- `main.gb`: шапка `.gb-head` — марка кассы и название кофейни, часы, звук, на весь экран, «Назад в TS». Кнопки шапки гаснут, пока их не трогают (`.gb-fade`).
- Две колонки `.gb-col[data-kind]`: «Готовится» (preparing) и «Готово — заберите» (ready). Готовая колонка — подложка из `gb-ready` 7% поверх `bg`, заголовок `gb-ready-ink`, карточки номеров с рамкой `gb-ready`.
- Номера `.gb-num` в сетке `.gb-numbers`: число колонок, промежуток и размер шрифта экран подбирает сам, чтобы все номера влезли (в окне 1280×800 — 220 и 320px).
- Номер — тот же, что на кассе в «Заказ N» и на карточке бариста. Имени гостя здесь нет, только номер.
