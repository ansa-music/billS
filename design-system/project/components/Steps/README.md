# Steps

«Первые шаги» — семь шагов от регистрации до первой смены с полосой прогресса. CSS-паттерны `.start-head`, `.progress` и `ol.steps-list > li.step` (`apps/cloud-web/src/Start.tsx`).

- Шаг — карточка (`surface`, рамка, `radius`, `shadow`) с кнопкой-шапкой: круг с номером 34px, заголовок `title` и пояснение 14px `muted`.
- `data-state`: `done` — круг залит `accent` с «✓», заголовок `muted`; `current` — рамка карточки `accent` 60%, круг обведён `accent`; `todo` — серый круг. Открытый шаг показывает `.step-body` с действиями.
- Прогресс — «2 из 7» (650, `tabular-nums`) и полоса 8px `radius-pill`, заливка `accent`.
- Заголовок шага — повелительное наклонение: «Подключите кассу», «Войдите в кассу», «Проведите первую смену».
