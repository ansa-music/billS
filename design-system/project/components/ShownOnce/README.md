# ShownOnce

Секрет, который показывается один раз: предупреждение, значения и «Готово». Живой компонент `TS.ShownOnce` (`apps/cloud-web/src/cabinet-ui.tsx`).

- Потребитель кладёт внутрь значения (обычно `CopyValue`), передаёт `onDone` и, если нужно, `note` — пояснение под значениями.
- Блок `.new-key` — `surface-2`, рамка `border`, радиус `radius-md`, отступ 14px. Предупреждение — `warn`, смешанный с `text`: «Показывается один раз. Облако хранит только отпечаток — потом посмотреть нельзя, можно только выдать новый.»
- Показывайте на месте, без модального окна; «Готово» — обычная кнопка, не главная.
