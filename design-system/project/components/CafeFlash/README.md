# CafeFlash

«Заказ 1 — отправлен бариста»: подтверждение оплаты поверх колонки заказа на несколько секунд, потом касса готова к следующему гостю. Разметка — `.pos-flash` в `apps/web/src/cafe/Pos.tsx`, стили — `cafe/cafe.css`.

- Карточка `.pos-flash-card`: номер заказа крупно (`.pos-flash-number`), «✓ отправлен бариста», «С собой · 3 300 ₸», сдача (`.pos-flash-change`; без сдачи — «Без сдачи», `data-zero`) и маленькие кнопки «Печать чека» и «Дальше».
- Полоска `.pos-flash-timer` внизу карточки убывает за время показа (`animation-duration`, 3 с). `data-state` — ok или ошибка отправки.
- Под ней — пустой заказ: значок чашки, «Нажмите на напиток — он сразу в заказе.», кнопка `.pos-repeat` «Повторить последний» с составом и подсказка по клавишам.
- Номер заказа — тот же, что гость увидит на экране заказов (`GuestBoard`).
