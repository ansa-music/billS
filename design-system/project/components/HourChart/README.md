# HourChart

Загрузка столов по часам за 7 дней — 24 столбика, пиковые часы светятся лампой. CSS-паттерн `.hours` внутри `figure.chart` (`apps/cloud-web/src/ClubPage.tsx`).

- Столбик — `.hour` с дорожкой `.hour-track` (`border` 50%) и заливкой `.hour-bar` цвета `felt`, высота в процентах от максимума, минимум 2px. Радиус `radius-bar`.
- Пик — `data-peak`: столбик `lamp` со свечением, подпись часа `lamp` 600. Пиков один-три, не больше.
- Подписи часов — каждые 3 часа, 11px, `muted`, `tabular-nums`. Подсказка на столбике (`title`): «20:00–21:00 · 18 ч · 23 игр · занятость 75 %».
- Под графиком — `figcaption` `muted`: «Пиковые часы: 20:00, 21:00 · занятость считается от всех столов клуба».
- Столбчатый график по дням (`.chart-bar`: `felt`, сегодня — `accent`, наведение — `felt-lit`; линия `lamp`; точки `danger`) собирается SVG в коде и в эту систему не перенесён.
