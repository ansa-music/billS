# EmptyState

Пустое место, где скоро будут данные: спокойная фраза и, если можно, следующий шаг. CSS-паттерн `.empty-state` (блок) и `.empty` (строка) из `bundle.css`.

- `.empty-state` — пунктирная рамка `border`, `surface`, радиус `radius`, отступ `space-20px`; внутри — `p.muted` или `h2` (`section-title`) и одна кнопка `btn-primary`.
- `.empty` — строка 14px `muted` внутри панели: «Везде спокойно — открытых тревог нет».
- Пишите, что здесь появится или что сделать: «Заведений пока нет.» + «Добавьте первое заведение». Без иллюстраций и эмодзи.
