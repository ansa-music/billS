# CabinetNav

Разделы кабинета — «Обзор · Заведения · Сотрудники · Уведомления · Скачать». Живой компонент `TS.CabinetNav` (`apps/cloud-web/src/CabinetNav.tsx`): ряд вкладок под верхней панелью на компьютере, нижняя панель с иконками на телефоне.

- Потребитель передаёт `route` — текущий маршрут. Активный раздел выводится из `route.kind`: отчёты заведения (`club`, `shifts`, `tariffs`, `bookings`, `start`) подсвечивают «Обзор», `company` — «Заведения», `phone` — «Уведомления», `apps` — «Скачать».
- Активный пункт на компьютере — заливка `accent` и текст `accent-text`; на телефоне — текст `accent` на подложке из `accent` 14%.
- Пункт — минимум `control` (44px) на компьютере и 54px на телефоне; иконки 20 и 24px, обводка 2px, `currentColor`.
- До 700px панель фиксируется внизу (`z-nav`, тень `shadow-nav-bottom`), а страница получает нижний отступ 96px. Карточка показывает вид для компьютера.
- Новый раздел добавляйте вместе с иконкой в том же стиле. Больше пяти пунктов на телефоне не поместится.
