# PosModal

Диалог кассы на нативном `<dialog>`: подтверждения и маленькие формы. Живой компонент `TS.PosModal` (`Modal` из `apps/web/src/ui.tsx`); закрывается по Escape и по клику на фон.

- Потребитель даёт `open`, `title`, `onClose` и содержимое. Кнопки кладите в `.modal-actions` (они делят ширину поровну) или в `.modal-foot` — закреплённый подвал.
- Вид: 640px (`.modal-wide` — 820px), `surface`, рамка `border`, радиус `radius-lg`, тень `shadow-lg`, фон `overlay`. Шапка 68px с заголовком `pos-dialog-title` и крестиком `control-lg`; тело — отступ `space-5`, промежуток `space-4`.
- Внутри всё крупнее: кнопки от `control-lg` и 18px, поля 52px и 18px, подсказки 16px — диалог в кофейне заполняют стоя, с шага.
- До 560px диалог превращается в лист на весь экран, кнопки закреплены внизу под большим пальцем.
- Окно — только для денег, отмен и коротких форм. Модификаторы и комментарии выбираются чипами без окна.
