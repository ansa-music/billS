# CopyValue

Значение моноширинным шрифтом в рамке и кнопка «Скопировать» — ключи сотрудников, временные пароли, данные для подключения кассы. Живой компонент `TS.CopyValue` (`apps/cloud-web/src/cabinet-ui.tsx`).

- Потребитель даёт `value`, необязательный `label` (13px, `muted`, от 120px) и `big` — для шестизначного ключа, который читают вслух (`key-big`: 34px, разрядка 0.18em).
- Значение — `key` (16px/600 `--font-mono`), `surface`, рамка `border`, радиус `radius-code`, выделяется целиком одним кликом.
- После нажатия кнопка пишет «Скопировано». Без доступа к буферу (http, старый браузер) текст выделяется, чтобы скопировать вручную.
- `TS.CopyButton` копирует длинный текст, не показывая его (подписанная лицензия).
