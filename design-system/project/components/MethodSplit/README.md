# MethodSplit

Деньги по способам оплаты одной строкой: «нал 31 000 ₸ · карта 47 500 ₸ · QR 6 000 ₸». Живой компонент `TS.MethodSplit` (`apps/cloud-web/src/shared.tsx`).

- Потребитель даёт `totals` (`cash`, `card`, `qr`, `total` в тиынах) и `currency`; `total` добавляет «итого» жирным, `className` — свой класс.
- Нулевые способы скрываются; если нулевые все — показываются все три.
- Подписи «нал», «карта», «QR», «итого» — `muted` и на 14% мельче суммы. Цифры — `tabular-nums`, переносится строка только между способами.
