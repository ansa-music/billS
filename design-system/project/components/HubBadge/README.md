# HubBadge

Связь заведения с кассой: «Касса на связи», «Нет связи с кассой 47 мин», «Касса ещё не выходила на связь», «Касса не подключена». Живой компонент `TS.HubBadge` (`apps/cloud-web/src/shared.tsx`).

- Потребитель даёт `hub` (`HubStatus` или `null` — касса не подключена) и `now` (мс) — от него считается, сколько нет связи.
- Точка 8px и слово 13px/600: на связи — `accent`, нет связи — `danger`, не подключена — `muted` с пунктирной точкой.
- `pendingSettings` добавляет тег `.tag-warn` «ждёт настройки»: кабинет отправил настройки, касса их ещё не забрала.
- При наведении — время последней связи в UTC. Ставьте в правый край шапки карточки или страницы.
