# Section

Панель с заголовком — основной контейнер страниц кабинета. Живой компонент `TS.Section` (`apps/cloud-web/src/shared.tsx`) рисует `section.panel` со строкой `.panel-head`.

- Потребитель даёт `title` (`title`, 16px/650), необязательный `aside` — правый край шапки (счётчик `.panel-total`, тег, маленькая кнопка) — и содержимое.
- Панель: `surface`, рамка `border`, радиус `radius`, тень `shadow`, отступ `space-4`×`space-18px` (на телефоне 14px), промежуток `space-3`.
- Несколько значков справа собирайте в `.panel-aside`. Таблицу внутри оборачивайте в `.grid-wrap` — она выйдет к краям панели и будет прокручиваться.
- Панели не вкладываются друг в друга. Для вложенного блока есть `.sub-panel` на `surface-2`.
