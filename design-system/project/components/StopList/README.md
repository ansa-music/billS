# StopList

«Стоп-лист»: что закончилось. Нажатие на позицию убирает её с кассы, повторное — возвращает. Диалог `.modal.modal-wide` (`apps/web/src/cafe/StopList.tsx`), открывается кнопкой «Стоп-лист» на экране бариста.

- Позиции сгруппированы по категориям меню: `section.stop-group` с заголовком `h3.cash-sub` и списком `ul.stop-list`.
- Позиция — кнопка `.stop-item` во всю ширину с `aria-pressed`: `false` — тег `tag-ok` «есть», `true` — подсветка и тег `tag-danger` «нет в наличии». Пока запрос идёт, все позиции недоступны.
- Над списком подсказка: «Нажмите на позицию, которая закончилась: на кассе она пропадёт. Нажмите ещё раз, когда появится.»; в подвале — одна главная кнопка «Готово».
- Карточка показывает диалог статично, без затемнения фона.
