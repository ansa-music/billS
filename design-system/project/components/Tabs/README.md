# Tabs

Вкладки внутри страницы заведения: «Обзор · Смены · Тарифы · Сотрудники». CSS-паттерн `.tabs` (`apps/cloud-web/src/ClubPage.tsx`) — `nav` со ссылками.

- Потребитель даёт ссылки; текущая получает `aria-current="page"` — она становится `surface` с тенью `shadow` и текстом `text`, остальные — `muted`.
- Подложка — `surface-2` с рамкой `border`, радиус `radius-md`, отступ 3px; вкладка — `radius-inner`, 14px/600.
- Вкладки переключают страницы (ссылки). Чтобы выбрать значение внутри формы, берите `Segmented`.
