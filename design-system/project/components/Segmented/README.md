# Segmented

Переключатель из двух-пяти вариантов внутри формы: способ входа, срок лицензии. CSS-паттерн `.seg` из `bundle.css`.

- Разметка — кнопки с `role="tab"` или `role="radio"` и `aria-selected`; выбранная — `surface`, текст `text`, тень `shadow-seg`; остальные — `muted`.
- Подложка — `surface-2`, рамка `border`, радиус `radius-md`, отступ `space-1`; кнопка 38px, 14px/600, радиус `radius-inner`.
- `.seg` — две равные колонки. `.seg.seg-wrap` — гибкий ряд с переносом для трёх и более вариантов.
- Переключение страниц — это `Tabs`, а не сегменты.
