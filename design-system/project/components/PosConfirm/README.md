# PosConfirm

Подтверждение необратимого действия в диалоге: вопрос, что произойдёт, «Отмена» и действие. Живой компонент `TS.PosConfirm` (`Confirm` из `apps/web/src/ui.tsx`) поверх `PosModal`.

- Потребитель даёт `open`, `title` (вопрос: «Отозвать ключ?»), `text` (последствия и что делать дальше), `confirmLabel` (глагол: «Отозвать»), `danger` — красная кнопка, `busy` — обе кнопки недоступны, `onConfirm`, `onCancel`.
- Кнопки: `btn-ghost` «Отмена» и `btn-primary` или `btn-danger` с действием; по 56px и 18px, поровну по ширине.
- Подтверждения ставят только перед деньгами и отменами. Текст говорит о последствии, а не пугает: «Ключ перестанет работать сразу; все входы по нему закроются. Если он нужен, выдайте новый.»
