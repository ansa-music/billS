# BaristaBoard

Экран бариста (KDS): три колонки «Новые → Готовятся → Готовы», одна большая кнопка на карточке, цвет по стадии и времени ожидания. Разметка — `apps/web/src/cafe/Barista.tsx`, стили — `cafe/staff-touch.css` (`.kds-*`).

- Шапка `.kds-bar`: «3 в работе», «Всего в работе» — сколько каждой позиции сделать по всем заказам (`.kds-allday`), инструменты: «Выданные», «Стоп-лист», «Экран гостей», «Звук», на весь экран.
- Колонка `.kds-col[data-stage]` с полосой цвета стадии сверху: `kds-new` (= `info`), `kds-prep`, `kds-ready`. Цвета стадий — токены, в светлой теме темнее.
- Карточка `.kds-card`: номер заказа крупно, «С собой» / «Здесь», таймер с момента заказа (в «Готовы» — с момента «Готово»), позиции «2× Капучино» с добавками. `data-age` — ok, затем жёлтый и красный по времени ожидания; готовая карточка в рамке `kds-ready`.
- Добавка, которую нельзя перепутать (растительное молоко, без лактозы, декаф), — `.kds-opt[data-attn]` цветом `kds-attn` на своей подложке; она же — в строке «Всего в работе».
- Кнопка `.kds-next` (64px, 800): «Начать» (`kds-new`, текст `on-info`), «Готово» (`kds-prep`, текст `bg`), «Выдан» (`kds-ready`, текст `kds-on-ready`). Рядом — «‹» назад на прошлую стадию.
- После перехода внизу появляется `.kds-undo`: «Заказ 2 → «Готовится»» и «Вернуть».
- Раскладка по ширине: от 1000px три равные колонки, 600–999px — «Готовы» узкой колонкой, до 600px — вкладки `.kds-tabs`. С 600px экран заполняет окно по высоте (`--fill-h`), колонки прокручиваются внутри.
