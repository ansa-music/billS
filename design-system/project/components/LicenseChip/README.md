# LicenseChip

Цветной чип состояния лицензии: «Действует», «Скоро закончится», «Последний день», «Истекла»… Живой компонент `TS.LicenseChip` (`apps/cloud-web/src/cabinet-ui.tsx`); `TS.LicenseLine` добавляет срок: «до 07.11.2026 · осталось 5 дней».

- Потребитель даёт `status` (`LicenseStatus`; `null` — «Нет лицензии»).
- Тона: `ok` — `accent` (действует); `warn` — `warn`, смешанный с `text` (скоро закончится, ещё не началась); `danger` — `danger` на `danger-soft` (последний день, истекла, заблокирована, другой филиал, подпись не прошла); остальное — `muted` на `surface-2`.
- Форма — `chip` 12px/600, `radius-pill`, рамка цвета тона на 50%. Чип всегда со словом, не только цветом.
