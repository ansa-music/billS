# CafePos

Экран кассы кофейни у стойки: меню плитками слева, заказ справа, оплата в одно нажатие. Разметка — `apps/web/src/cafe/Pos.tsx`, стили — `cafe/cafe.css` и `cafe/pos-touch.css` (в `bundle.css` под `data-surface="pos"`). Карточка — статичная копия живого экрана.

- Раскладка: `section.page.pos[data-mode="order"][data-layout="split"] > .pos-grid` — колонка меню `.pos-menu` и колонка заказа `.pos-side` шириной 330–410px. До 960px заказ уезжает в нижний лист, который открывает полоса `.pos-bar`.
- Меню: строка `.pos-toolbar` (поиск с подсказкой «/», «×N» — количество для следующего товара, «Редактировать дизайн»), категории `.pos-tab` (первая — «★ Хиты», у остальных точка цвета категории) и сетка `.pos-tiles`.
- Плитка `.pos-tile` — название, цена крупно и «добавки», если у товара есть варианты. Цвет категории задаёт `style="--hue: N"`: кофе 55, чай 150, еда 25 (из настроек меню). `data-in-order` — плитка подсвечена, в углу счётчик `.pos-tile-count`.
- Заказ `.pos-order`: шапка «Заказ» со счётчиком и «Отложить» / «Очистить», строки `.pos-line` (название, количество − / +, сумма; у последней штуки вместо «−» корзина). Выбранная строка (`data-selected`) раскрывает добавки прямо под собой — `.pos-opts`: размер сегментами, молоко и сироп чипами с доплатой, готовые комментарии и своё поле. Окна для добавок нет.
- Подвал `.pos-foot`: «Здесь / С собой», имя гостя для экрана заказов, «Итого», три кнопки оплаты `.pos-express-btn` (`data-method` CASH, CARD, QR — подписи с клавишами Enter, F2, F3) и полоса `.pos-paybar` «Оплатить N ₸» для оплаты со сдачей или частями.
- Клавиатура: «/» — поиск, 2…9 — количество, Enter — наличные без сдачи, F2 — карта, F3 — QR, Esc — очистить.
