# Difference

Расхождение Z-отчёта: «сходится» зелёным, «излишек +1 500 ₸» или «недостача −2 300 ₸» красным. Живой компонент `TS.Difference` (`apps/cloud-web/src/shared.tsx`).

- Потребитель даёт `value` (тиыны; `null` — смена ещё открыта, показывается «—» серым) и `currency`. `words={false}` оставляет только число со знаком — для узких столбцов таблицы.
- Ноль — `accent`; любое расхождение, и излишек тоже, — `danger`, вес 650. Деньги не сошлись — это всегда повод проверить.
- Текст не обвиняет: в тревогах рядом пишут «Возможно, ошибка при пересчёте — проверьте Z-отчёт».
