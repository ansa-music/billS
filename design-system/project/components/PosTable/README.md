# PosTable

Таблица разделов кассы — сотрудники, журнал входов, отчёты. CSS-паттерн `.table-wrap > table.table` из `apps/web/src/app.css`: прокручивается внутри, а не вся страница.

- Ячейка 10×8px, 14px, разделитель `border` сверху. Заголовок — 13px/600 `muted`, обычный регистр (в отличие от таблиц кабинета, где он в верхнем регистре).
- Числа — `td.num` / `th.num`: по правому краю, табличные, без переноса. Неактивная строка (`data-inactive`) — `muted`.
- Действия строки — `.actions` справа: маленькие кнопки с промежутком `space-6px`.
- Состояние в ячейке — `PosTag`; пустое значение — «—» цвета `muted`.
