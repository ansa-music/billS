# CafeReports

Отчёты кофейни за смену: четыре плитки цифр, «Умные подсказки», оплаты по способам и «Что заказывают». Разметка — `apps/web/src/cafe/Reports.tsx` (`#/stats` при `data-business="cafe"`), стили — `sections.css`, `insights/insights.css`, `cafe/cafe.css`.

- `.stat-row` из `.stat-tile`: подпись, значение крупно, пояснение — «Выручка смены», «Чеков оплачено», «Средний чек», «Ждут бариста» (с временем до «Готово»).
- `section.section-card.insights` — подсказки по продажам за 4 недели, считаются на кассе без интернета; пока продаж мало — пустое состояние с лампочкой.
- `dl.kv.cafe-kv` — «Наличные / Карта / QR / Итого» (`kv-strong`), под ним ссылки на «Счета» (X- и Z-отчёт) и «Кабинет».
- `ul.cafe-top` — топ позиций: название, мягкая полоса `.cafe-top-bar` (ширина — доля от лидера), количество.
- Две колонки — `.two-col`.
