# BrandMark

Монограмма TS на плашке `brand-mark` — знак продукта в верхней панели, на экране загрузки и на входе. Живой компонент `TS.BrandMark` (`apps/cloud-web/src/BrandMark.tsx`): inline SVG, ему не нужен файл, и он одинаков везде; фавикон в `index.html` — тот же рисунок.

- Размер задаёт CSS: `.brand-mark` — 40×40, радиус `radius-sm`; в верхней панели на телефоне — 34px. Через `className` можно добавить свой класс размера.
- Рядом всегда название: `.brand` → марка + `h1` (`title-lg`) + подпись `muted` («Кабинет TS» или «Касса и учёт для заведения»), промежуток `space-3`.
- Не перекрашивайте: плашка #14211b, буквы белые, внутренняя обводка — белый 14%. Цвета зашиты в SVG и не зависят от темы.
- Для иконки приложения (512, 180) берите файл из группы «Logos», а не этот компонент.
