# AlertList

Список тревог: свет без игры, расхождение в кассе, проблемы с питанием. Живой компонент `TS.AlertList` (`apps/cloud-web/src/shared.tsx`).

- Потребитель даёт `alerts` (`CloudAlertView[]`), `timezone` заведения, `showClub` — подставлять название заведения — и `emptyText` («Везде спокойно — открытых тревог нет»).
- Открытая тревога — `danger-soft`, рамка `danger` 55%, время `danger` 600. Закрытая — `surface-2`, `opacity-resolved`, время `muted` и «закрыта 02.11, 16:20».
- Текст тревоги говорит, что проверить, и никого не называет: «Стол 4: свет горит без игры уже 12 мин — проверьте стол».
- Новая тревога в реальном времени дополнительно всплывает `Toast`.
