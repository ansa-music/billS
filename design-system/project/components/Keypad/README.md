# Keypad

Цифровая клавиатура входа по ключу из шести цифр — экран входа кассы на планшете. CSS-паттерн `.keypad` из `apps/web/src/app.css` (разметка — `apps/web/src/Login.tsx`).

- Сетка 3×4 до 340px, промежуток `space-10px`. Над ней — шесть точек `.keypad-dot` 14px: набранные залиты `accent`.
- Клавиша — 68px, `surface-2`, рамка `border`, радиус `radius-nav` (14px), цифры `pos-keypad` (28px/600, табличные). Под пальцем — подложка из `accent` 18%.
- Нижний ряд: «⌫» (`.keypad-erase`, 24px), «0» и «Войти» (`.keypad-enter`: `accent`, текст `accent-text`, 19px). «Войти» недоступна, пока не набраны все шесть цифр.
- Аппаратная клавиатура тоже работает: цифры, Backspace и Enter. При неверном ключе клавиатура вздрагивает (`data-shake`).
