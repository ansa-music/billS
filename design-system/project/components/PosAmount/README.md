# PosAmount

Крупная сумма с пояснением — «через зал»: к оплате, итог смены. CSS-паттерн `.amount` и `.amount-note` кассы (`apps/web/src/styles.css`, разметка — `TableCard.tsx`); рядом — `.timer` для времени игры.

- `.amount` — `pos-amount`: 28px/700, межстрочный 1.2, `-0.01em`, табличные цифры; на телефоне 24px.
- `.amount-note` — 13px/500 `muted` справа от суммы через 10px: «минимум 60 мин», «бесплатно ещё 4:12».
- `.timer` — `pos-timer`: 48px/700, `-0.03em`, межстрочный 1.05; на телефоне 40px.
- Шрифт кассы — Inter с `tnum`: цифры одной ширины, сумма и таймер не прыгают, пока тикают.
