# OfflineBanner

Жёлтый баннер, пока кабинет не может достучаться до облака: последние цифры остаются на экране. Живой компонент `TS.OfflineBanner` (`apps/cloud-web/src/shared.tsx`).

- Потребитель даёт `online`; при `true` компонент ничего не рисует.
- Подложка — `warn` 14% поверх `surface`, рамка `warn` 55%, радиус `radius-md`; мигающая точка `warn` (1.6 с, без мигания при reduced motion).
- Текст: жирное «Нет связи с облаком.» и что происходит дальше. Не пугайте и не просите ничего делать — страница обновится сама.
- Тем же видом рисуется баннер лицензии `.lic-banner`; `data-tone="danger"` переводит его в `danger-soft`.
