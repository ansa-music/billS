# StatTile

Плитка периода: выручка крупно, под ней «начислено», нал/карта/QR, возвраты, чеки и средний чек. Живой компонент `TS.StatTile` (`apps/cloud-web/src/shared.tsx`).

- Потребитель даёт `label` («Сегодня», «Последние 7 дней», «С начала месяца»), `stats` (`PeriodStats`, деньги в тиынах) и `currency` (`KZT`).
- `big` — итоги компании наверху обзора: `surface`, тень `shadow`, сумма `stat-big` (30px). Обычная плитка — на `surface-2` внутри панели или карточки, сумма 20px.
- `compact` — для карточки заведения: без строки игр, часов и среднего чека.
- Выручка — это оплачено минус возвраты (что реально взяла касса); «начислено» — сумма на «Стоп». Возвраты — `danger`, только когда они есть. Отменённые игры добавляются в конец строки.
- Плитки ставьте по три в ряд в `.stats` (промежуток `space-10px`). Подпись — `overline`.
